📖 Guia de Uso do Sistema

⚙️ 1. Configuração Inicial

Personalize os nomes dos 4 avaliadores conforme sua equipe. Clique em "Salvar Nomes" para aplicar as mudanças.

➕ 2. Cadastrar Tarefas

Preencha todos os campos obrigatórios:

  • Descrição: Nome ou descrição da tarefa/projeto
  • Estágio: Selecione o status atual (ATRASADO, EM PLANEJAMENTO, INICIADO, EM EXECUÇÃO, CONCLUÍDO)
  • Notas: Cada avaliador atribui uma nota de 1 a 5

Campos opcionais:

  • Data de Vencimento: usada para alertas de prazo (vence hoje e vencidas)
  • Custo Estimado: valor formatado automaticamente em moeda (R$)

A média é calculada automaticamente e determina a prioridade da tarefa.

Tarefas com a média empatada são ordenadas por estágio. O estágio, ATRASADO tem prioridade máxima.

📋 3. Gerenciar Tarefas na Lista

Alterar Estágio: Use o dropdown na coluna "Estágio" para mudar rapidamente o status.

Editar: Clique no ícone ✏️ para modificar todos os dados da tarefa.

Excluir: Clique no ícone 🗑️ para remover a tarefa (confirmação necessária).

🔍 4. Filtros e Controles

Filtrar por Estágio: Selecione um estágio específico no dropdown para ver apenas essas tarefas.

Filtrar por Prazo: Use o filtro de prazo para listar apenas tarefas que vencem hoje ou já estão vencidas.

Ordenação:

  • Por padrão, tarefas são ordenadas por prioridade (maior média primeiro)
  • Clique em "ORDEM ALFABÉTICA" para ordenar por descrição
  • Clique em "ORDEM POR PRIORIDADE" para voltar à ordenação por média

Resumo da Tabela: Exibe total de tarefas, tarefas filtradas, vencendo hoje, vencidas e soma de custo do que está em exibição.

Limpar Filtros: Remove todos os filtros aplicados.

🖨️ 5. Impressão em PDF

Clique em "IMPRIMIR PDF" para gerar uma versão otimizada para impressão:

  • Fonte Times New Roman, tamanho 10pt
  • Inclui rodapé com data/hora de impressão e copyright
  • Na janela de impressão, selecione "Salvar como PDF" para gerar o arquivo

🎨 6. Código de Cores

Estágios:

  • 🟢 EM EXECUÇÃO: Verde - tarefa sendo executada
  • 🔴 ATRASADO: Vermelho - tarefa com atraso
  • ⚪ INICIADO: Cinza claro - tarefa iniciada
  • 🟠 EM PLANEJAMENTO: Laranja - em fase de planejamento
  • ⚫ CONCLUÍDO: Cinza escuro - tarefa finalizada

Médias:

  • 🟢 Verde: Média ≥ 4 (alta prioridade)
  • 🟡 Amarelo: Média entre 3 e 3.99 (média prioridade)
  • 🔴 Vermelho: Média < 3 (baixa prioridade)

Prazos:

  • ⏰ Laranja: tarefa com vencimento hoje
  • ⚠️ Vermelho: tarefa vencida (exceto quando concluída)

💾 7. Salvar e Carregar Projetos do Banco de Dados

Guarde seus projetos na nuvem (Supabase) e acesse de qualquer lugar!

📌 Botão "💾 SALVAR TAREFA"

Ao clicar, abre uma lista com todos os projetos salvos. Você pode:

  • Clicar em um projeto existente: Escolha a ação:
    • 🔄 Atualizar - Sobrescreve o projeto com os dados atuais
    • 💾 Salvar Como Novo - Cria uma cópia com timestamp
  • Clicar em "➕ Novo Projeto": Digite o nome e salve um novo projeto
    • A lista de tarefas NÃO pode estar vazia
    • Todas as tarefas DEVEM ter um estágio definido

📥 Botão "📥 CARREGAR TAREFA"

Abre uma lista dos últimos 10 projetos salvos. Clique diretamente no projeto desejado para restaurar todos os dados na tela.

⚠️ Importante

Os dados são salvos em um banco de dados na nuvem. Certifique-se de que:

  • Tem conexão com a internet
  • Não há tarefas com estágio vazio antes de salvar
  • A lista não está vazia

🎨 8. Armazenamento de Dados Local

Além do banco de dados, suas tarefas atuais são salvas automaticamente no navegador (localStorage). Os dados permanecem mesmo após fechar a página.

Atenção: Limpar dados ou trocar de navegador apagará todas as tarefas locais não salvas.
